Put `expenditure_lstm_model.tflite` in this folder.

It's generated by running `ml/convert_model_to_tflite.py` locally (see
`ml/README.md`) — it isn't committed here because it has to be built with
the TensorFlow version you trained the model with.

Until this file exists, ExpenditurePredictionService.isAvailable will be
false and the app will show "prediction unavailable" instead of crashing.
